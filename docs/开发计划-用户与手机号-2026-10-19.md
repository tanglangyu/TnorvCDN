# 开发计划：手机号国别码 + 用户管理功能丰富（2026-10-19）

## 目标
1. 系统所有手机号统一存含国别码格式 `0086xxxxxxxxx`（默认 0086，登录可选国别，发码接口暂只允许 0086）。
2. 管理端 /cdn/users 页面功能太少且看不到用户全量信息 —— 系统性丰富：每页至少新增 5 个功能。

## D1 手机号国别码体系

### 后端
- 新增 `PhoneUtil`（Services/PhoneUtil.cs）：
  - `Normalize(string input, string cc="0086")`：`+86/86/0086/裸11位` → `0086` + 号码；其它国别前缀原样保留（`00XX…`）。
  - `IsValid(string normalized)`：0086 → `^00861[3-9]\d{9}$`；其它国别前缀 → 结构合法但发送被拒。
  - `CountryOf(normalized)`：取 `00\d{2,4}` 前缀。
  - `Mask(normalized)`：保留国别码 + 前3后4。
- SmsService.SendCodeAsync：
  - 入口 Normalize；`CountryOf != "0086"` → 拒绝"该国家/地区暂未开放短信服务"。
  - 限流 key、验证码 key、日志 Mobile 全部用 normalized 值。
  - NotifyAsync / VerifyCode 同样 Normalize 后比较。
- 登录（AdminEndpoints）：phone 登录先 Normalize 再 VerifyCode + 查询 `SmsPhone == normalized`。
- 存量数据迁移（启动 DDL 后执行一次 SQL）：
  `UPDATE "Users" SET "SmsPhone"='0086'||"SmsPhone" WHERE "SmsPhone" ~ '^1[3-9]\d{9}$';`
  SmsLogs.Mobile 同步前缀化。
- SmsEndpoints：send-code 接受 `countryCode` 字段（默认 0086），拼进 Normalize；notify 设置接口返回/保存含国别码，掩码用 PhoneUtil.Mask。

### 前端
- UserConsole / AdminConsole 登录页手机号 tab：手机号输入框前加国别选择（el-select，+86 0086 中国大陆 默认；其它选项 disabled 显示"暂未开放"）；提交 `{ mobile, countryCode }`；本地校验按所选国别（0086 校验 1[3-9]\d{9}）。
- notify.vue 绑定手机号：同样加国别选择。
- sms.ts API：send 增加 countryCode 可选参数。

## D2 /cdn/users 用户管理丰富

### 后端（AdminEndpoints + AdminExtraEndpoints）
1. 列表接口扩展字段：SmsPhone（掩码）、BalanceCents、Features、站点数（子查询）、会话数。
2. `GET /admin/users/{id}/detail`：全量信息 —— 基本信息、身份认证（UserIdentity）、订阅（含套餐名）、站点列表、登录会话、最近 20 条短信日志、工单统计、订单统计。
3. `PUT /admin/users/{id}` 扩展：`smsPhone`（管理员直填，Normalize 校验，查重）、`features`（用户级功能开关 JSON，null=跟随套餐）、`remark`？不加备注列（避免 schema 膨胀，features 已够）。
4. `POST /admin/users/{id}/force-logout`：删除该用户全部 UserSession 并逐条 kick（SignalR）。
5. `GET /admin/users/{id}/sms-logs`：该用户手机号短信日志分页。

### 前端 users_list.vue
1. 列表列扩展：手机号（掩码）、余额（元）、站点数、创建时间（已有）。
2. 行操作新增「详情」→ el-drawer 全量详情，Tab：基本信息 / 站点与套餐 / 登录会话 / 短信日志 / 订单与工单。
3. 编辑对话框扩展：手机号（可清空重绑）、功能开关区（复用 FEATURE_LABELS 22 项，三态：跟随套餐/强制开/强制关 → 存 features JSON）。
4. 新增「调整余额」快捷对话框（调 /finance/adjust-balance，带原因必填）。
5. 新增「强制下线」按钮（force-logout）。
6. 新增「重置密码」独立按钮（原先藏在编辑里，现在编辑+快捷重置都保留）。
7. 顺手修复：users_invitations.vue / users_setting.vue 删除邀请码 URL 缺 `/admin` 前缀（404 bug）。

## 交付顺序
后端（PhoneUtil → SmsService → 登录/端点 → DDL 迁移）→ 双前端登录页 → users 后端 → users 前端 → 构建 + 部署 + 实测（发码 0086 通过、非 0086 拒绝、登录、用户详情/强踢/余额调整）。
