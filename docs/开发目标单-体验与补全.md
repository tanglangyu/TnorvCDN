## A. 管理端（AdminConsole）逐页开发目标

### A1. 网站列表 `/cdn/servers`（核心页，投入最重）
**用户故事**：管理员打开页面 3 秒内看到全部站点健康度；能搜索/筛选/排序；对单站做最常用 5 个操作不需进二级页。
**交互规格**：
- 工具条：搜索框（防抖 300ms，域名模糊）· 集群/用户/状态三下拉 · 批量按钮（启停/删/换集群/换源站）· 新增向导按钮
- 表格：分页（20/50/100，后端分页）· 列排序（域名/请求数/流量/状态）· 列显隐下拉 · 状态列 = 运行点（绿/灰/红）+ SSL 徽标 + 备案徽标
- 行操作折叠为「管理」下拉：设置/日志/统计/证书/刷新缓存/复制/删除（危险二次确认输入域名）
- 新增站点改为 3 步向导弹窗（域名→源站→确认配置摘要），保存后直接跳站点设置
- 顶部统计条：站点总数/运行中/停用/证书临期（14 天内）四枚可点击筛选 chip
**后端**：`GET /admin/servers` 补 `page/pageSize/sort/order/sslExpiring` 参数

### A2. 财务模块（bills/income/accounts/orders/fee）
**用户故事**：财务人员能对账：月收入趋势、订单流水、用户余额调整有据可查。
**交互规格**：
- `/cdn/finance/income` 重做：月收入汇总卡（本月/上月/环比）+ 近 12 月收入柱状（CSS 柱，复用看板模式）+ 订单类型饼分布（CSS 环）
- `/cdn/finance/bills`：真实账单列表（月结：用户×月份×流量/请求/金额），支持月份筛选 + 导出 CSV
- `/cdn/finance/accounts`：用户余额列表 + 余额调整弹窗（调整原因必填，写审计）
- orders：状态 tab（全部/待支付/已支付/已取消）+ 订单详情抽屉（含支付回调时间线）
**后端**：新增 `GET /admin/finance/income-summary`、`GET /admin/finance/bills`（月结聚合）、`POST /admin/finance/adjust-balance`

### A3. 数据看板 `/dashboard`
**交互规格**：
- 实时指标条加 60s 迷你趋势火花线（近 30 点，CSS 实现）
- 排行表点击行下钻（域名→该站点近 24h 小时趋势弹层）
- 状态码分布点击 4xx/5xx → 跳访问日志页带 status 预筛选
- 所有空态统一组件（插图 + 一句话引导 + 主操作按钮）
**后端**：`GET /admin/stats/top` 支持 `serverId` 下钻维度

### A4. 访问日志 `/cdn/servers/logs`
**交互规格**：状态码彩色 chip · URI 可点击复制 · 筛选记忆（localStorage）· 状态码/站点/时间三维预筛选（从看板跳转带参）· 「实时尾随」开关（3s 轮询追加，最多 200 条缓冲）
**后端**：`GET /admin/logs` 补 `status` 筛选参数

### A5. 用户管理 `/cdn/users`
**交互规格**：用户行展开 = 该用户站点列表 + 套餐 + 余额摘要；功能开关改行内快捷开关（弹窗确认）；新增「 impersonate 预览」按钮（以该用户视角打开用户端首页，只读提示条 3s 自动消失）
**后端**：`GET /admin/users` 补 `includeStats`（站点数/余额/套餐聚合）

### A6. 集群页 `/cdn/clusters`
**交互规格**：节点行内联带宽/CPU 迷你条（实时指标合并进列表，免跳转）；设置抽屉 6 tab 保持；「安装节点」命令复制卡（一键复制 curl 安装命令）
**后端**：`GET /admin/clusters` 返回内联 `metrics`（从 NodeMetricsRegistry 取）

### A7. 其余页面统一打磨（一次性）
- 所有 CRUD 轻量页（优惠券/邀请码/流量包/资源包/NS 域名/SSH 授权）：补空态插图、危险操作 MessageBox、创建后表单重置、列表 loading 骨架
- 证书页：到期进度条（<14 天橙、<7 天红）+ 一键续期按钮
- 审计/操作日志：操作类型筛选下拉 + 关键词搜索

## B. 用户端（UserConsole）逐页开发目标

### U1. 证书页 `/servers/certs`（先修 500）
**交互规格**：证书卡片化（域名、来源徽标、到期环形进度、剩余天数）；临期（<14 天）顶部提醒条 + 「续期」按钮（对 auto 站点触发 renew 指令）；上传证书弹窗（粘贴 PEM 即时校验域名/到期并预览）
**后端**：修 SelectMany 翻译错误；`POST /user/servers/{id}/ssl/renew`

### U2. 我的站点 `/servers`
**交互规格**：站点卡片视图（默认）/表格视图切换；卡片 = 域名大字 + 运行状态点 + 今日流量/请求/命中率三迷你数 + 启停开关；「快速接入」三步引导（CNAME 值一键复制 → 源站填写 → 完成）；分组标签筛选 chips
**后端**：`GET /user/servers` 补 `stats=true`（今日流量/请求/命中率聚合）

### U3. 用量统计 `/servers/traffic-stats`
**交互规格**：站点下拉 + 时间范围切换（24h/7d/30d）；流量+请求双轴 CSS 柱状；表格含流量列（当前缺）；超出套餐流量时顶部进度条告警
**后端**：`GET /user/traffic-stats` 补 `serverId/days` 参数，回 bytes 字段

### U4. WAF 安全组（logs/iplists/settings）
**交互规格**：
- 拦截日志：原因分类 chips 筛选（CC/UA/地域/防盗链）+ IP 点击弹出该 IP 全部拦截记录（复用 ipbox 模式用户侧简化版）
- 拦截 IP 页：调 `/user/waf/logs` 聚合保留，但补「加黑名单」按钮 → 写到本人站点 Security.IpBlacklist（归属校验）
- 全局规则页改名「我的防护」：展示本人各站点的 CC/5秒盾/防盗链启用状态矩阵 + 行内快捷开关
**后端**：`PUT /user/servers/{id}/security` 已有，前端接线即可；`GET /user/waf/summary` 补按站点分组

### U5. 财务 `/finance/*`
**交互规格**：总览页 = 余额大数字卡（+充值按钮）+ 本月消费/本月流量进度环 + 近 6 笔订单；充值页支持自定义金额+套餐快捷金额；账单/明细表加类型筛选与合计行
**后端**：`GET /user/finance/summary`（余额/月消费/月流量聚合）

### U6. 消息与工单
**交互规格**：消息页未读分组置顶 + 全部已读/批量删除；工单详情对话气泡式（用户右蓝/客服左灰）+ 回复框固定底部 + 状态徽标（进行中/已回复/已关闭）；新建工单加分类选择与优先级
**后端**：`GET /user/tickets/{id}` 补回复时间线（现有 Reply 字段展开为列表）

### U7. 套餐页 `/plans`
**交互规格**：套餐卡对比表（当前套餐高亮 + 差异列勾叉）；购买流程弹窗化（选月数→用券→确认金额→余额支付）全程不跳页；余额不足时内嵌「去充值」快捷按钮
**后端**：无新增（orders 已有，前端串联）

### U8. 智能 DNS `/ns/domains`
**交互规格**：记录行内编辑（点击值即编辑框）；批量页保留；生效状态列加「重新同步」按钮；解析检测按钮（A 记录查询展示）
**后端**：`POST /user/ns/domains/{id}/sync`（触发 SyncUserRecordAsync 重试）
