# TnorvCDN 控制台视觉风格规范

> 适用项目:`src/web/RapidDev.AdminConsole`(管理后台, 5181)、`src/web/RapidDev.UserConsole`(用户控制台, 5182)。
> 本规范定义系统的正式风格;后续新页面一律遵循,不再视为"迁移过渡"。

## 1. 总则

- **风格基底**:Element Plus(全量引入,`zhCn` 语言包),扁平、轻量、中密度后台风格。
- **设计令牌**:一律通过 Element Plus CSS 变量取色/取值,禁止硬编码色值(品牌色、暗色模式自动适配)。特例:白色图标 `#fff`、纯黑遮罩等极端值可例外。
- **迁移垫片**:`src/styles/main.scss` 中的 Bootstrap/Tabler 工具类垫片(row/col、d-flex、mb-*、text-muted、avatar 等)是历史页面的兜底层,**新页面禁止使用**;新页面用 el-row/el-col、el 自身布局或 scoped 样式。

## 2. 颜色

| 令牌 | 值 | 用途 |
|---|---|---|
| 主色 primary | `#409EFF`(Element Plus 默认,不覆盖) | 品牌色、主按钮、选中态、链接 |
| 语义色 | success / warning / danger / info,均为 EP 默认 | 状态、标签、图表 |
| 文本 | `--el-text-color-primary` / `regular` / `secondary` | 标题 / 正文 / 次要说明 |
| 填充/边框 | `--el-fill-color(-light)`、`--el-border-color(-light)` | 底色、分割线 |

- 浅色底色块统一用 `--el-color-*-light-8 / light-9`。
- 暗色模式:仅依赖 `html.dark` + EP dark css-vars,组件内**不得**写死浅色背景色。

## 3. 字体与排版

- 字体栈(全局):`-apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, 'PingFang SC', 'Microsoft YaHei', sans-serif`。
- 层级:页面标题 20px/600 → 卡片标题 14-15px/600 → 正文 14px/400 → 辅助文字 13px → 小标签 12px(大写/字距可选,如 `.subheader` 风格)。
- 数字强调(统计大数字):24-32px/600,`--el-text-color-primary`。

## 4. 布局骨架

- 侧栏:宽 260px(收起 64px),**浅色,跟随 `--el-bg-color`**,右边框 `--el-border-color`;菜单项 hover `--el-fill-color-light`,active `--el-color-primary-light-9` + 主色文字。
- 顶栏:高 56px(`--rapiddev-header-height`),与侧栏同底色、底边框分割。
- 内容区:padding 1.5rem;页面最大宽度不限,表单页建议限宽 1200px。
- 两个控制台共享同一套布局与令牌(`--rapiddev-*`)。

## 5. 组件规范

- **卡片 el-card**:`shadow="never"` + 默认边框(即 TCard 默认形态);可悬浮卡片才用 `hover` 或 `.card-hover`。圆角使用 EP 默认(4px);登录页等独立卡片可用 10px。
- **表格 el-table**:默认尺寸,`stripe`,列表页统一放卡片内;空文案必须中文。
- **表单 el-form**:`label-position="top"`(登录、弹窗小表单)或默认 label-left(设置类页面),size="large" 用于登录,其余 default。
- **弹窗/抽屉**:确认类操作用 ElMessageBox.confirm;复杂编辑优先 el-drawer。
- **标签 el-tag**:`effect="light"` 为主,状态列小尺寸 `size="small"`;禁止大面积实心 `effect="dark"`。
- **按钮**:主操作 type="primary";危险操作 type="danger";行内操作用 `link` 型;图标统一 `ti ti-*`(Tabler 图标字体,保留)。
- **反馈**:成功/失败用 ElMessage;加载用 el-button 自带 loading / v-loading。

## 6. 图标

- 统一使用 `@tabler/icons-webfont` 的 `ti ti-*` 字体图标(约 189 处存量引用,不再改动)。
- 不引入 Element Plus 图标组件混合使用;新图标先查 Tabler 图标库。

## 7. 页面模式(标准套路)

- **列表页**:page-header(标题+主操作按钮) → el-card 内 [TSearchForm → TTable → 分页],即 TCrud 组合。
- **统计卡页(dashboard)**:el-row/el-col 栅格,统计卡 = 大数字(.h1 风格) + .subheader 小标题 + 圆形浅底图标 avatar。
- **详情/个人中心页**:顶部横幅卡(渐变浅底 `--el-color-primary-light-9` → `--el-bg-color`) + 左右分栏 el-descriptions / el-table。
- **登录页**:居中 420px 卡片,浅主色渐变背景,顶部品牌 logo 方块。

## 8. 浮层空间(弹窗 / 抽屉 / 确认框)

> 语义源自框架原前端(TModal / TDrawer):遮罩高斯模糊 + 居中 + 尺寸分档。EP 实现如下。

- **遮罩**:EP 默认黑色半透明遮罩,不追加 blur(如确需高斯模糊,统一加 `.el-overlay { backdrop-filter: blur(4px); }` 于 main.scss,两项目保持一致)。
- **弹窗 el-dialog**:
  - 尺寸分档(对应原 modal-sm/md/lg/xl):sm 420px / md 600px / lg 900px / xl 1200px,宽屏优先用 px 而非百分比;
  - 垂直居中 `align-center`;内容超出时 `el-dialog` 自带滚动;
  - 内边距沿用 EP 默认(容器 16px,body 0),**禁止**再给 body 加 padding 或覆盖 `--el-dialog-padding-primary`;字段间距交给 `.el-form-item` 默认 margin-bottom 18px;
  - header:标题 16px/600(EP 默认),右上关闭按钮不换图标;
  - footer:右对齐,主按钮 type="primary",次按钮默认;取消在左、确定在右;
  - 表单类弹窗宽度 ≥ 600px 时字段用 el-row gutter=16 两列排布。
- **抽屉 el-drawer**:复杂/长表单编辑优先用抽屉(替代原 TDrawer offcanvas);默认宽 480px,表单类 600-720px;header/body/footer 结构同 EP 默认,footer 右对齐按钮组,规则同弹窗 footer。
- **确认框**:删除等危险确认统一 `ElMessageBox.confirm`,danger 按钮配 `type: 'warning'` 图标;禁止用 `window.confirm` / 原生 alert。
- **层级**:弹窗 z-index 全部交给 EP 自动管理,业务代码不得手写 z-index(原 TModal 的 9999 写法废除)。

## 9. 列表空间(表格 / 分页 / 工具条)

> 语义源自框架 TTable(table-vcenter card-table / striped / hover / compact)与 TPagination。

- **表格 el-table**:
  - 默认尺寸(行高约 40px,对应原 table-vcenter),仅超密数据页才用 `size="small"`;
  - 斑马纹 `stripe` 默认开,hover 高亮保持 EP 默认;不用竖向边框(对应原不默认 bordered);
  - 统一放在 el-card 内,卡片 body padding 0,表格紧贴卡片边缘(对应原 card-table);
  - 表头不加底色(EP 默认浅灰),列宽用 `min-width` 弹性分配,操作列 `fixed="right"` 宽度固定;
  - 空状态文案必须中文(如"暂无数据"),用 el-table 内置 empty。
- **分页 el-pagination**:右对齐,放表格卡片底部独立一行;`background`、`layout="total, sizes, prev, pager, next, jumper"`;每页条数默认 20。
- **工具条(搜索 + 操作)**:列表页顶部先 TSearchForm(搜索条件一行,查询/重置按钮右侧),再操作按钮行(新增/批量删除等,主操作 primary、批量删除 danger plain);按钮行与表格间距 12-16px。
- **标签 el-tag**:状态列一律 `size="small"` + `effect="light"`;运行中/启用=success,停用=info,异常/拦截=danger,待处理=warning;允许 `round` 但同列保持一致。

## 10. 反馈空间(toast / 通知)

> 语义源自框架 request.ts 错误 toast 与 useNotification 的右上角 toast(标题 + 时间 + 正文)。

- **操作结果(轻提示)**:成功/失败/警告一律 `ElMessage`(右上顶部居中弹出,3s 自动关闭):成功 `ElMessage.success('xx成功')`,失败把后端 message 透出 `ElMessage.error(msg)`;禁止再手写 DOM toast(框架原 request.ts 的 innerHTML toast 已废弃)。
- **全局通知(带正文/时间)**:SignalR 推送等需要标题+正文+时间的信息,用 `ElNotification`(右上角,自动关闭 4.5s):title=通知标题,message=正文,类型按语义 danger/info/success;通知铃铛面板内用 el-badge 未读数 + el-scrollbar 列表,条目 = 图标 + 标题 + 时间(13px secondary)。
- **加载**:
  - 按钮级:el-button 自带 `loading`(提交/查询中);
  - 区域级:`v-loading` 指令(表格卡片、详情块),文案可省略;
  - 页面级(路由懒加载):保持现有进度条/骨架,不引入全屏 loading 蒙层。
- **时序**:同一操作不重复提示;请求 401/会话被踢时只弹一次并跳登录。

## 11. 间距与密度速查

| 场景 | 值 |
|---|---|
| 弹窗内字段间距 | el-form-item 默认 18px(不改) |
| 弹窗/抽屉 footer 与 body | EP 默认(header/footer 自带 padding) |
| 折行栅格行间距 | el-row 栅格用 gutter;若用 flex `.row` 需 `row-gap: 16px` |
| 表格卡片 body padding | 0(表格贴边),分页行内 padding 12px |
| 工具条与表格 | 12-16px |
| 卡片纵向堆叠 | 16px(row-gap 或 el-row margin,禁止 0) |

## 13. 视觉打磨批(2026-10-17,已上线)

- **页面切换**:layout 的 RouterView 包 `<transition name="page" mode="out-in">`,样式在 main.scss(.page-enter/leave,18/12ms 位移淡入);`prefers-reduced-motion` 下自动关闭。
- **统计卡入场**:统计卡行加 `.stat-stagger`,直接子项依次 50ms 级联上浮(animation backwards + nth-child delay)。
- **数字排版**:`.h1/.h2/.h3` 全局 `font-variant-numeric: tabular-nums`,统计大数字不跳动。
- **顶栏毛玻璃**:`color-mix(in srgb, var(--el-bg-color) 82%, transparent)` + `backdrop-filter: saturate(160%) blur(8px)`,sticky;侧栏保持不透明。
- **侧栏活动项**:左侧 3px 圆角主色指示条(::before);折叠态 native title 提示。
- **返回顶部**:layout 主内容区尾部 `<el-backtop :right="24" :bottom="24" />`。
- **品牌/登录 Logo**:主色 135° 渐变 + light-5 投影;登录卡圆角 10px(规范 §7 既定)。
- **文本选区**:全局 `::selection` 用 `--el-color-primary-light-7`。
- **弹窗垂直居中**:短表单弹窗逐个加 `align-center`(不在全局强制,避免长内容弹窗顶部裁切)。
- 两控制台(main.scss 与 layout 样式)必须同步修改,保持一致。
